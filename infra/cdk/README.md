# CDK Skeleton

ECS Fargate frontend/backend/worker、ALB、企業IdP（候補: Microsoft Entra ID）、SQS、IAM/KMSなどの目標構成を、採用するサービスと要件が確定した後にここへ追加する。

このディレクトリは現時点では雛形であり、ローカルComposeの実行環境や本番認証の実装を提供しない。目標構成の全体像は[docs/architecture/aws/aws-architecture.md](../../docs/architecture/aws/aws-architecture.md)、現行コードの範囲は[docs/reference/current-implementation.md](../../docs/reference/current-implementation.md)を参照する。
