# response-format.md

## 1. コード変更後の回答

コード変更後の回答には以下を含める。

* 変更概要
* 変更ファイル
* 実行したチェック
* 実行できなかったチェックと理由
* 仕様上の注意点
* 残課題

## 2. コード修正依頼時の回答

コード修正依頼の場合は、修正箇所と前後のコードが分かるように説明する。

## 3. 実行できなかった場合

lint / test / build などを実行できなかった場合は、以下を明記する。

* 実行できなかったコマンド
* 実行できなかった理由
* 未確認のリスク
* ユーザー側で確認すべきコマンド

## 4. 画面確認が必要な場合

フロントエンド変更後に画面確認が必要な場合は、以下を明記する。

* 確認すべきURL
* 確認すべき画面
* 確認すべき操作
* 画面反映されない場合の確認手順
