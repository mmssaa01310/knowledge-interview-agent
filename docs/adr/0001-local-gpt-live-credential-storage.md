# ローカルOpenAI APIキーの保管

ローカル導入では、全テナント共通のOpenAI Project APIキーをローカルPostgreSQLへAES-256-GCMで暗号化して保存し、復号鍵はAPIプロセスのローカル環境設定でDBから分離する。現行ではこのキーをGPT-Live接続に使用する。キーを設定できるのは`applicationSettingsAdmin`権限を持つ管理者だけとする。Browserへ生のキーは返さず、設定画面へは先頭8文字と末尾4文字を残し、実際のキー長に合わせた`*`で間を隠したプレビューを返す。ログ、監査本文へ生のキーを記録しない。これにより、管理画面からの設定を可能にしつつ、DBだけが漏えいした場合にOpenAIキーを読めない構成にする。
