# ソース配布時の情報管理

配布するソース、説明、テストデータには、開発者や利用組織の実名、連絡先、所属、居住地、個人アカウント、開発端末固有のパスを含めない。

テストで人名や組織名が必要な場合は、甲野・乙野などの架空の人物、サンプル開発部、株式会社Example、地域A・地域Bなどの架空データを使用する。本リポジトリのこれらの例はすべて架空であり、実在の人物・組織のプロフィールを表さない。入力と期待値は同時に変更し、名前の訂正や空白の正規化など、検証している条件を維持する。

OpenAIなどの連携サービス名、依存ライブラリの名称、第三者の著作権表示・ライセンス、技術文書や研究の出典は、機能説明や利用条件に必要な情報として保持する。

## 配布物の作成

作業内容をコミットした後、Git管理下のソースをアーカイブする。

```bash
git archive --format=zip --output=../ai-interviewer-source.zip HEAD
```

この方法で作成したアーカイブには、Git履歴、リモートURL、コミット作成者、作業用の`.git`、Git管理対象外の`.env`や依存関係フォルダは含まれない。配布前にアーカイブのファイル一覧も確認する。Git管理下にある生成物や画像・動画は含まれるため、不要なものは配布対象から除外し、使用する素材は表示内容・音声・メタデータを確認する。

稼働中のPostgreSQLデータ、アップロード済み文書、会話履歴、APIキー、ログ、Dockerボリュームをソースと同梱しない。これらの実データの削除は、ソース内の架空化とは別の作業として扱う。

リポジトリ自体を共有する場合は、過去のコミットに残る情報も対象になる。最新ソースの架空化だけでは過去の履歴は変更されないため、履歴を含めて共有するか、履歴のない配布用リポジトリを作るかを配布前に決める。
