# Domain docs

## 作業前に読むファイル

- ルートの`GLOSSARY.md`
- `docs/adr/`にある、作業対象に関係するADR

これらのファイルがまだない場合は、そのまま作業を続けます。用語や判断が実際に決まった時点で、必要なファイルだけを作成します。

## 配置

このリポジトリは単一コンテキスト構成です。

- 用語集: ルートの`GLOSSARY.md`
- ADR: `docs/adr/`

## 用語の扱い

Issue、提案、仮説、テスト名でドメイン用語を使うときは、`GLOSSARY.md`の定義に合わせます。必要な用語が未定義なら、既存語の言い換えで済むかを確認し、本当に必要な場合に用語の追加を検討します。

## ADRとの矛盾

提案が既存ADRと矛盾する場合は、黙って上書きせず、該当ADRと矛盾点を示します。
