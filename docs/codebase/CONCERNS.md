# 注意点と未確定事項

## 1. セキュリティ

| 項目 | 現状 | 継続事項 |
| --- | --- | --- |
| OpenAI Project APIキー | AES-GCMでDB保存、管理者限定、画面ではマスク | 暗号化キーをDB外の安全な設定で管理する |
| 認証 | アプリ内ログインとサーバー側セッション | 本番公開前に運用環境に合わせた認証・セッション保護を見直す |
| AI出力 | Backendで検証し、承認前の候補として保存 | AI出力を自動で正式ナレッジ化しない |

## 2. 技術的負債

- `entity_store`はJSONB主体であり、検索量が増えたらクエリ・索引を見直す。
- Workerの非同期ジョブ処理はサンプル段階である。
- 実GPT Liveの音声品質はブラウザー・ネットワークごとの確認が必要である。

## 3. 変更が慎重な領域

- 認証・Record認可とテナント境界
- Interview Stateの状態遷移と承認境界
- OpenAIキーの暗号化・復号・画面表示
- GPT LiveのWebRTCイベントとResponses API委譲
